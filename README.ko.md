# myFlowForge

**AI 코딩 에이전트를 위한 조종석 — 당신의 책상 위에, 당신의 서버에, 당신의 주머니 속에.**

**Claude Code, Codex, Cursor, Gemini, qoder, opencode, DeepSeek** 그리고 그 밖의 도구들을 한곳에 모으는 데스크톱 조종석 — 그래서 **대화 도중에 에이전트와 모델을 갈아탈 수 있고**, **여러 프로젝트를 동시에 만들어 나갈 수 있고**, **가벼운 수동 기어 워크플로**로 작업의 형태를 잡을 수 있고, 스테이지 사이사이에 자신만의 **훅**을 엮어 넣을 수 있고, 이 전부를 **다른 컴퓨터나 휴대폰에서** 다룰 수 있다.

## myFlowForge란?

AI 코딩 CLI는 저마다 자기 터미널 안에서, 자기 세션 상태와 자기 할당량을 들고, 다른 도구들이 존재한다는 사실도 모른 채 살아간다. 하나를 고르면 그 작업이 끝날 때까지 그 하나와 결혼하는 셈이다.

**myFlowForge는 그것들을 한 지붕 아래에 둔다.** 에이전트와 모델은 세션이 아니라 *매 턴*의 속성이다 — 그래서 Claude Opus로 설계를 끝까지 궁리하고, 구현은 Codex에 넘기고, 마무리 정리는 값싼 모델로 떨어뜨리는 일을 전부 하나의 대화 안에서, 맥락을 유지한 채 할 수 있다.

그 위에 **가벼운 워크플로**가 얹힌다. 당신을 두고 저 혼자 달아나는 조립 라인이 아니라, 같은 대화 위에 얇게 덧씌운 구조다. 모든 스테이지는 당신이 *다음*을 누를 때까지 기다린다.

그리고 이 전부는 한 대의 기계에 묶여 있지 않다. 같은 조종석이 **다른 컴퓨터에 연결되어** — 당신의 Linux 머신, 사무실 데스크톱 — *그 기계의* 저장소에서 *그 기계의* 에이전트를 몬다. 휴대폰에서는 실행을 지켜보고, 게이트에 답하고, 대화를 계속 이어 갈 수 있다.

> **프로젝트 상태:** 활발히 개발 중인 개인 프로젝트. macOS, Windows, Linux 모두 패키징된 빌드를 배포하고, 휴대폰 클라이언트용 Android APK도 있다. 앱은 아직 어느 플랫폼에서도 코드 서명이 되어 있지 않다.

## ✨ 결국 중요한 여섯 가지

### 1. 애용하는 하나가 아니라, 에이전트의 집합

열네 개의 코딩 CLI가 하나의 인터페이스 안에서 공존한다: **Claude Code · Codex · Cursor · Gemini · qoder · opencode · Qwen · Copilot · Pi · Kimi · Reasonix · Trae · Antigravity · DeepSeek**.

모델 목록은 **각 CLI의 실제 로컬 설정에서 읽어 온다** — 하드코딩된 것이 없으므로, 보이는 것이 곧 당신 계정이 실제로 돌릴 수 있는 것이다. 직접 항목을 추가할 수도 있고, 추가한 것은 다음 새로고침에도 살아남는다. **opencode**는 그 자체가 다중 벤더 게이트웨이다: 한 번 연결하면 여러 곳에 닿는다.

### 2. 하나의 세션 안에서 에이전트와 모델 바꾸기

에이전트, 모델, 권한 모드는 입력창 아래에 놓인 세 개의 선택기다. 다음 메시지를 보내기 전에 아무거나 바꾸면 된다:

- 한 모델이 멈추거나 삼천포로 빠진다 → 갈아타고 계속 물어보라; 지금까지의 대화를 그대로 본다.
- 한 공급자의 할당량이 떨어졌다 → 같은 세션에서 다른 쪽으로 갈아타라.
- 생각은 비싼 모델로, 잡일은 싼 모델로.

네이티브 resume를 지원하는 에이전트(Claude Code, Codex, Cursor, qoder, opencode)는 자기 세션 히스토리를 이어 간다. 나머지는 myFlowForge가 맥락을 재구성한다. 어느 쪽이든 당신은 그냥 계속 이야기하면 된다.

### 3. 여러 프로젝트를 동시에 개발하기

하나의 워크스페이스가 **여러 저장소**를 담는다. 스테이지는 *프로젝트별로 팬아웃*할 수 있다: 프런트엔드, 백엔드, SDK가 동시에 전진하고, 각각 자기 **git worktree** 안에서 자기 에이전트가 몰기 때문에 절대 충돌하지 않는다 — 그리고 모든 diff는 하나의 변경 사항 패널에 모여 검토를 기다린다.

팬아웃은 일부만 골라도 된다: 다섯 저장소를 전부 분석하되 코드는 둘에만 쓰는 것도 지극히 정상적인 구성이다.

### 4. 가벼운 워크플로 — 수동 기어로

워크플로를 시작한다고 해서 끝까지 달려가도록 놓아두는 것이 **아니다**. 대화형 모드로 진입할 뿐이다:

- 리본이 *M단계 중 N단계 · 현재 스테이지 · 누가 몰고 있는지*를 보여 준다.
- 그 스테이지의 에이전트는 **당신 눈앞의 대화 안에서** 일한다 — 출력, 도구 호출, 파일 쓰기가 전부 보인다.
- 마음에 안 드는가? 그냥 계속 이야기하라. 후속 질문과 수정은 스테이지를 다시 돌리지 않는다.
- 만족스러운가? **다음**을 눌러라. 그때에야 비로소 핸드오프가 쓰이고 다음 에이전트가 들어온다.

설계 스테이지는 프로젝트별로 절이 나뉜 **진짜 마크다운 문서**(`forge-docs/design.md`)를 쓴다. 손실 있는 요약이 아니라 바로 그 문서가 에이전트를 가로지르는 유일한 계약이다; 하위 에이전트들은 전문을 읽고 자기 절에 집중한다.

게이트가 걸린 스테이지는 멈춰서 당신을 기다린다: **승인**, **되돌려 보내기**(당신의 메모가 맨 위에 고정되고, 직전 출력이 기준선으로 되먹여진다), 아니면 재실행을 유발하지 않는 **단순한 질문**. 설계가 틀렸다는 걸 뒤늦게 깨달았는가? 앞선 스테이지로 되돌아가 다시 하면 된다.

### 5. 스테이지 사이의 훅

훅은 스테이지 **사이에** 끼워 넣는 작은 단계다 — 스테이지가 에이전트가 진짜 엔지니어링을 하는 자리라면, 훅은 가는 길에 처리하는 잡일이다.

**실행 전**, **특정 스테이지 뒤**, 또는 **실행 전체가 끝난 뒤**에 붙일 수 있다: 최신 코드 받아 오기, 설계 문서를 위키에 동기화하기, 린트 돌리기, 보드 갱신하기, 알림 보내기.

각 훅은 워크스페이스 루트에서 **제한된 마이크로 에이전트**로 돌아간다 — 주어진 스킬과 도구, 그리고 과제와 상류에서 만들어진 산출물만 쥔다. 결과는 한 줄로 보고하고, 사람만 풀 수 있는 문제에 부딪히면 당신에게 직접 묻는다. 실패는 파이프라인을 **막고** 재시도 / 건너뛰기 / 중단을 제안한다. 훅은 어떤 슬롯에도 매이지 않은 전역 라이브러리에 산다: 한 번 쓰고, 아무 데나 붙여라.

### 6. 당신의 기계들, 그리고 당신의 휴대폰

연결된 호스트는 터미널 버튼 옆, **상태 표시줄의 스위치**다. 그것을 넘기면 워크스페이스 목록, 세션, 실행 중인 에이전트, git 변경 사항, 내장 터미널이 전부 *그 기계의 것*이 된다.

- LAN을 통한 **직접 연결**, 또는 **SSH**, 또는 두 기계가 서로를 볼 수 없을 때는 **종단 간 암호화 중계**. 중계는 오직 암호문만 옮긴다 — 세션을 읽을 수 없고, 방은 데몬의 공개 키에서 유도된다.
- 헤드리스 Linux 머신에서는 **데몬**을 돌려라: `myflowforge-daemon pair`가 터미널에 바로 QR 코드를 찍어 준다. 스캔하면 페어링 끝이다.
- **휴대폰 클라이언트**(iOS & Android)는 뷰어가 아니라 진짜 클라이언트다: 흘러가는 대화를 읽고, 권한 게이트와 플랜 게이트에 답하고, 변경된 파일을 훑고, 워크스페이스를 만들고, 워크플로를 편집하고, 호스트를 바꾼다.

> **DeepSeek**은 DeepSeek Harness다 — `npm install -g @deepseek-ai/dsh`. 헤드리스 플래그가 아니라 프로필로 런타임 형태를 고르는데, myFlowForge는 `headless` 쪽을 몰고, 세 가지 권한 등급은 각각 `read-only` / `workspace-write` / `danger-full-access`에 대응된다. 키는 `dsh web`(Models 페이지)이나 `DEEPSEEK_API_KEY`로 넣어 주면 된다.
>
> **Trae**(ByteDance의 TraeCode CLI)는 npm으로 배포되지 않는다 — 공식 `install.sh`가 `traecli`를 `~/.local/bin`에 두므로 그 경로가 PATH에 있는지 확인하라. 워크플로 안에서 사람 손 없이 편집하게 하려면 `traecli config edit`을 실행해 `permission_mode: bypass_permissions`를 설정하라.

myFlowForge는 **API 키를 저장하지 않고 요청을 중계하지도 않는다** — 당신의 기계에 이미 설치되고 인증된 CLI를 몰 뿐이다. 빠진 것은 설정에서 설치 안내와 함께 표시되고, 설정은 CLI가 설치는 되었지만 로그인되지 않은 경우도 알려 준다.

## 🔧 실행은 어떤 모양인가

```
   목표를 설명한다
            │
            ▼
  ┌── 훅 ──┐        ┌── 훅 ──┐                    ┌── 훅 ──┐
  │  실행  │        │  설계  │                    │  실행  │
  │   전   │        │   후   │                    │   후   │
  └───┬────┘        └───┬────┘                    └───┬────┘
      ▼                 ▼                             ▼
 📋 요구사항 →  🎨 설계 →  ✋ 게이트 →  💻 개발 → 🧪 테스트 → 🔍 리뷰
    (명확화)   (design.md)  직접 결정    (팬아웃)    (검증)  (다중 시점)
                      │                       │
                      │                       └─ 프로젝트당 에이전트 하나,
                      │                          병렬 레인, 각자의 worktree
                      └─ 진짜 문서, 하류의 모든 에이전트가 전문을 읽는다

 모든 화살표는 당신이 "다음"을 누를 때까지 기다린다. 스테이지는 추가, 삭제,
 순서 변경, 건너뛰기가 가능하다 — 요구사항 → 개발만 돌리는 것도 완전히 유효하다.
```

같은 게이트에 닿는 세 가지 시작 방법:

1. 워크플로 패널에서 **시작**을 누른다.
2. 입력창에 `/`를 치고 하나 고른다.
3. 완결된 개발 과제를 평범한 말로 설명한다 — 메인 에이전트가 그것을 알아보고 MCP를 통해 플랜 게이트를 올린다. 질문, 논의, 한 줄짜리 수정은 이것을 건드리지 않는다.

## 📱 원격 호스트와 휴대폰 클라이언트

하나의 앱, 여러 대의 기계. 상태 표시줄에서 호스트를 고르면 모든 것이 그것을 따라간다.

| | |
|---|---|
| **직접** | 같은 LAN, 데몬의 포트로 곧장. 토큰 인증. |
| **SSH** | 이미 가지고 있는 SSH 로그인을 재사용 — 새로 열 것이 없다. |
| **중계** | 서로를 볼 수 없는 기계들을 위해. **종단 간 암호화**: 세션마다 새 키, 중계는 암호문만 전달하고, 읽을 수 없는 프레임은 신뢰하지 않고 버린다. 직접 운영할 수 있다 (`relay/`, Node 또는 Cloudflare Worker) — 배포 절차는 `relay/README.md`에 있다. |

**Linux 데몬**은 창이 없는 같은 코드베이스다 — tarball을 설치하고, systemd 아래에서 돌리고, 터미널에 찍히는 QR 코드를 스캔해 페어링하라 (`docs/linux-deploy.md`).

**휴대폰 클라이언트**는 책상을 떠나 있을 때 실제로 필요한 부분들을 담는다: 흐르는 사고, 도구 카드, 서브 에이전트 카드가 있는 실시간 대화; 답할 수 있는 권한 게이트와 플랜 게이트; 변경된 파일과 diff; 워크스페이스 생성; 워크플로 템플릿 라이브러리; 호스트 전환과 QR 페어링. 마크다운, 표, 로컬 이미지는 네이티브로 렌더링된다 — 원격 이미지 주소는 의도적으로 링크로 남겨 두어, 에이전트의 출력이 당신의 휴대폰을 추적 비콘으로 바꾸는 일이 절대 없게 한다.

## 🧩 상자 안에 함께 든 것들

- **네이티브 세션 가져오기** — 로컬 Claude / Codex / Cursor / qoder 히스토리를 읽기 전용으로 훑고, 워크스페이스로 가져와 이어 간다.
- **MCP 브리지** — 내장 Forge MCP 서버가 에이전트로 하여금 앱을 되불러 오게 한다: `forge_ask`, `forge_propose_plan`, `forge_write_artifact`, `forge_handoff`, `forge_delegate`, `forge_read_context`, `forge_heartbeat`. MCP를 지원하는 에이전트에는 주입되고, 나머지는 텍스트 지시문으로 대체된다.
- **MCP 서버와 애드온** — 각 CLI가 어떤 MCP 서버를 설정해 두었는지 보고, 앱에서 승인하거나 취소하고, 스킬 마켓을 둘러보며 그것을 읽는 CLI에 스킬을 설치한다.
- **메모리** — 에이전트가 되읽을 수 있는 워크스페이스별 메모, 그래서 오래 가는 작업이 자기 실타래를 유지한다.
- **실시간 관측 가능성** — 흐르는 사고 / 도구 호출 / 파일 변경 / 원본 출력, 필터 가능한 로그 콘솔, 실행 히스토리, 그리고 프로젝트를 가로지르는 변경 증거.
- **토큰 사용량과 할당량** — 공급자별 남은 할당량과 초기화 시각, 그리고 워크스페이스 × 에이전트 × 일자별 지출.
- **봇 브리지** — **DingTalk**, **Telegram**, **Feishu**에서 휴대폰으로 게이트에 답하고, 결과를 확인하고, 대화를 시작하고, 워크플로를 몬다.
- **권한 모드** — 읽기 전용 · 워크스페이스 자동(기본값) · 전체 접근, 세션별 또는 스테이지별로. 각 CLI의 실제 샌드박스 범위에 대응되고, UI는 어떤 에이전트가 실제로 그것을 지키는지 분명히 말해 준다.
- **슬래시 명령, 스킬, 플러그인** — `/`가 디스크에 실제로 있는 명령과 설치된 스킬을 에이전트별로 걸러 보여 준다.
- **사용자 정의 워크플로** — 프로세스는 당신이 조립하는 것이다: 각자 자기 스테이지 집합을 가진 이름 붙은 워크플로를 원하는 만큼 저장하라; 모든 스테이지는 자기 에이전트, 모델, 권한 모드, 팬아웃 형태, 게이트 여부, 문서 산출 의무 여부를 고른다.
- **사용자 정의 스테이지** — 어떤 워크플로에서든 참조할 수 있는, 당신만의 전역 스테이지 라이브러리.
- **파일 브라우저와 diff** — 변경 표시가 붙은 전체 화면 트리, 구문 강조 미리보기, diff/전문 토글.
- **내장 터미널** — 워크스페이스에 뿌리내린 진짜 pty, 공급자별 프록시와 시간대 설정과 함께. 원격 호스트에 연결되어 있으면 **그 기계의** 셸을 연다.
- **데스크톱 펫** — 당신이 보고 있는 화면을 따라다니고, 에이전트 활동을 미리 보여 주고, 확인 카드를 띄운다; 펫 마켓을 둘러보거나 자기 이미지를 가져와도 된다.
- **성장 펫** — 데스크톱 펫이 당신이 일하는 동안 단계를 밟아 자라나므로, 긴 세션이 눈에 보이는 무언가를 남긴다.
- **투명도와 프로스티드 글래스** — 하나의 블러 슬라이더가 창 전체를 완전 불투명에서 세 가지 네이티브 macOS 비브런시 재질까지 옮겨 놓아, 당신의 데스크톱이 비쳐 보이게 한다.
- **개인화** — 6종의 오리지널 스킨, 12가지 강조색, 300장이 넘는 배경화면 갤러리 또는 당신의 사진, 앱과 대화에 각각 독립적인 픽셀 단위 글꼴 크기, 밝은 테마와 어두운 테마 각각 따로 조율된 대비.
- **배경화면 기반 테마** — 켜 두면 전체 팔레트가 당신이 고른 배경화면에서 유도되고, 밝게 갈지 어둡게 갈지는 이미지 자신이 정한다. 배경화면은 오직 두 개의 색상만 기여하고, 모든 명도와 채도 단계는 손으로 조율한 스킨에서 그대로 복사되므로, 산만한 사진이라도 읽을 수 없는 인터페이스를 만들어 낼 수 없다. 강조색만은 직접 고르고 싶은가? 하나 고르면 강조색만 따라오기를 멈춘다.
- **대화 속 이미지와 인라인 비주얼** — 에이전트가 디스크에 만들어 낸 이미지는 답변 안에서 렌더링되고, 클릭하면 원본 크기로 볼 수 있다. 답변 도중에 쓰인 HTML 조각은 진짜 카드, 표, 다이어그램으로 렌더링될 수 있다(기본값은 꺼짐). 절대 `innerHTML`을 쓰지 않는다 — 조각은 파싱된 뒤 구성적 허용 목록으로 재구축되고, 색은 오직 테마 토큰에서만 올 수 있으므로, 렌더링된 내용이 당신의 스킨과 싸우는 대신 그것을 따른다.

## 📥 내려받기와 설치

[**Releases**](https://github.com/flowForges/myFlowForge/releases) 페이지에서 최신 빌드를 받아라:

| 플랫폼 | 파일 |
|----------|------|
| macOS · Apple Silicon (M1–M4) | `myFlowForge-<version>-arm64.dmg` |
| macOS · Intel | `myFlowForge-<version>.dmg` |
| Windows · x64 | `myFlowForge-<version>-x64-setup.exe` |
| Android | `myFlowForge-<version>.apk` |
| Linux · 헤드리스 데몬 | `myFlowForge-daemon-<version>-linux.tar.gz` |

> **앱은 코드 서명이 되어 있지 않다.** macOS에서 첫 실행 시 *"열 수 없습니다"* 또는 *"손상되었습니다"*라고 뜰 수 있다 — 서명되지 않은 앱은 원래 그렇게 보이며, 파일 자체는 멀쩡하다. **우클릭** → **열기** → **열기**를 하거나, 다음을 한 번 실행하라:
> `xattr -dr com.apple.quarantine /Applications/myFlowForge.app`
> Windows SmartScreen에서는 **추가 정보 → 실행**을 눌러야 한다.
>
> myFlowForge는 바로 이 Releases 피드를 확인해 더 새로운 버전을 앱 안에서 제안한다.

**iOS**는 내려받기로 배포되지 않는다 — `mobile/`에서 당신의 Apple ID로 직접 빌드해 케이블로 기기에 설치하라.

## 🚀 시작하기

**사전 요구 사항:** macOS 11+ / Windows 10+ / 최신 Linux, Node.js ≥ 20, git, 그리고 설치되고 인증된 지원 코딩 CLI 최소 하나.

```bash
git clone https://github.com/flowForges/myFlowForge.git
cd myFlowForge
npm install
npm run dev          # dev mode with renderer hot reload
```

| 명령 | 하는 일 |
|---------|--------------|
| `npm run dev` | 핫 리로드로 시작 |
| `npm test` | 전체 테스트 스위트 실행 (Vitest) |
| `npm run typecheck` | main과 renderer 두 tsconfig를 모두 타입 검사 |
| `npm run build` | 프로덕션 번들 빌드 |
| `npm run dist:mac-all` | Intel과 Apple Silicon `.dmg`를 모두 빌드 |
| `npm run dist:win` | Windows x64 설치 프로그램 빌드 |
| `npm run check:daemon` | 헤드리스 데몬을 처음부터 끝까지 점검 |

휴대폰 클라이언트는 `mobile/`(Expo / React Native)에, 중계는 `relay/`에 있다; 둘 다 자기 `package.json`을 가진다.

산출물은 `release/`에 떨어진다. `src/main/**` 아래의 변경은 **Electron 완전 재시작**이 필요하다 — 핫 리로드는 renderer만 새로 고친다.

## 📁 프로젝트 구조

```
src/
├── main/              # Electron 메인 프로세스
│   ├── agents/        # CLI 어댑터 + provider 레지스트리, 탐지, 권한
│   ├── run/           # 워크플로 엔진: 스테이지, 게이트, 팬아웃, 훅, 핸드오프
│   ├── chat/          # 워크스페이스별 대화, 큐, 메모리
│   ├── mcp/           # Forge MCP 서버 (에이전트 → 앱 브리지)
│   ├── remote/        # 원격 호스트: 직접 / SSH / 중계, 라우팅, E2E 채널
│   ├── daemon/        # 헤드리스 데몬 + 터미널 QR 페어링
│   ├── bot/           # 봇 브리지 (DingTalk / Telegram / Feishu 전송)
│   ├── plugins/       # 플러그인 호스트, 카탈로그, 스케줄러, 확장 지점
│   ├── sessionImport/ # 네이티브 세션 스캔 및 가져오기
│   ├── usage/         # 공급자 할당량 어댑터
│   ├── pet/           # 데스크톱 펫 창
│   └── ...            # git, fs, 터미널, 업데이트, 감시자, 창, 외관
├── renderer/          # React UI (뷰, 컴포넌트, 설정, 테마, 펫)
├── preload/           # 컨텍스트 격리된 IPC 브리지
└── shared/            # 프로세스 간 공유되는 타입과 순수 로직
mobile/                # iOS & Android 클라이언트 (Expo / React Native)
relay/                 # 종단 간 암호화 중계 (Node 또는 Cloudflare Worker)
```
