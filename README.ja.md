# myFlowForge

**AI コーディングエージェントのためのコックピット — デスクの上でも、サーバー上でも、ポケットの中でも。**

**Claude Code, Codex, Cursor, Gemini, qoder, opencode, DeepSeek** をはじめとする各種エージェントを一箇所に集めたデスクトップ・コックピット。**会話の途中でエージェントとモデルを切り替え**、**複数のプロジェクトを並行して開発**し、**軽量な手動ギアのワークフロー**で作業を形づくり、ステージの間に自分の **hook** を織り込み、そのすべてを **別のマシンやスマートフォン** から操作できます。

## myFlowForge とは?

AI コーディング CLI はどれも自分専用のターミナルの中で動き、自分だけのセッション状態と自分だけのクォータを持ち、ほかの CLI の存在を知りません。ひとつ選んだら、そのタスクが終わるまで添い遂げることになります。

**myFlowForge はそれらをひとつ屋根の下にまとめます。** エージェントとモデルは *ターン単位* のプロパティであってセッションのものではありません。だから Claude Opus で設計を練り、実装を Codex に渡し、後片付けは安いモデルに落とす、といったことが、文脈を保ったままひとつの会話の中でできます。

その上に載るのが **軽量なワークフロー** です。勝手に暴走していく組み立てラインではなく、同じ会話に薄く構造をかぶせただけのもの。どのステージも、あなたが *次へ* を押すまで待ちます。

そしてそのどれも 1 台のマシンに縛られません。同じコックピットが **別のコンピューター** — 自宅の Linux マシン、オフィスのデスクトップ — に接続し、*そのマシンの* リポジトリで *そのマシンの* エージェントを動かします。スマートフォンからは、実行の様子を眺め、ゲートに答え、会話を続けられます。

> **プロジェクトの状態:** 現在も開発が続いている個人プロジェクトです。macOS、Windows、Linux のいずれもパッケージ済みビルドを配布しており、スマートフォンクライアント用の Android APK もあります。アプリはまだどのプラットフォームでもコード署名されていません。

## ✨ 本当に大事な 6 つのこと

### 1. お気に入りの 1 本ではなく、エージェントのコレクション

14 種類のコーディング CLI がひとつの画面で共存します: **Claude Code · Codex · Cursor · Gemini · qoder · opencode · Qwen · Copilot · Pi · Kimi · Reasonix · Trae · Antigravity · DeepSeek**。

モデル一覧は **各 CLI の実際のローカル設定から読み取ります** — ハードコードは一切ないので、見えているものがあなたのアカウントで実際に動かせるものです。手で項目を追加することもでき、次回の更新でも消えません。**opencode** はそれ自体がマルチベンダーのゲートウェイなので、一度つなげば多くに届きます。

### 2. ひとつのセッションの中でエージェントとモデルを切り替える

エージェント、モデル、権限モードは入力欄の下に並ぶ 3 つのセレクターです。次のメッセージを送る前に、どれでも変更できます:

- あるモデルが止まったり脱線したりした → 切り替えてそのまま質問を続ける。ここまでの会話は見えています。
- あるプロバイダーのクォータを使い切った → 同じセッションのまま別のプロバイダーへ。
- 考える作業には高いモデル、力仕事には安いモデル。

ネイティブ resume を持つエージェント (Claude Code, Codex, Cursor, qoder, opencode) は自分自身のセッション履歴を引き継ぎます。それ以外については myFlowForge が文脈を再構成します。どちらにせよ、あなたはただ話し続けるだけです。

### 3. 複数のプロジェクトを同時に開発

ワークスペースは **複数のリポジトリ** を抱えられます。ステージは *プロジェクトごとにファンアウト* できます: フロントエンド、バックエンド、SDK が同時に進み、それぞれが自分の **git worktree** の中で自分のエージェントに動かされるのでぶつかりません — そして差分はすべて 1 つの変更パネルに集まってレビューできます。

ファンアウトは部分集合でも構いません。5 つのリポジトリすべてを解析して、コードを書くのはそのうち 2 つだけ、というのはごく普通の構成です。

### 4. 軽量なワークフロー — 手動ギアで

ワークフローを開始しても、最後まで一気に走り出すことは **ありません**。会話モードに入るだけです:

- リボンに *M 個中 N 番目のステップ · 現在のステージ · どのエージェントが動かしているか* が表示されます。
- そのステージのエージェントは **目の前のチャットの中で** 作業します — 出力もツール呼び出しもファイル書き込みも、すべて見えます。
- 気に入らない? そのまま話しかけてください。追加の指示や修正でステージが再実行されることはありません。
- 満足した? **次へ** を押します。そのときはじめて引き継ぎが書かれ、次のエージェントが呼ばれます。

設計ステージは **本物の markdown ドキュメント** (`forge-docs/design.md`) を、プロジェクトごとにセクション分けして書きます。そのドキュメントこそが — 情報の落ちた要約ではなく — エージェント間の唯一の契約です。下流のエージェントは全文を読んだうえで、自分のセクションに集中します。

ゲート付きのステージは停止してあなたを待ちます: **承認**、**差し戻し** (あなたのメモが先頭に固定され、前回の出力がベースラインとして戻されます)、あるいは再実行を起こさずに **質問するだけ**。設計が間違っていたと後から気づいた? 前のステージに戻ってやり直せます。

### 5. ステージの間の hook

hook はステージとステージの **間** に差し込む小さなステップです。ステージが本物のエンジニアリングをするエージェントだとすれば、hook はそのついでに片付ける雑用です。

**実行前**、**任意のステージの後**、**実行全体の後** に取り付けられます: 最新のコードを取得する、設計ドキュメントを wiki に同期する、lint を走らせる、ボードを更新する、通知を送る。

各 hook はワークスペースのルートで **制限された微小エージェント** として動きます — 与えられたスキルとツール、そしてタスクと上流で生成された成果物だけを持ちます。結果は 1 行で報告し、人間にしか解決できないことに突き当たったらあなたに直接尋ねます。失敗はパイプラインを **ブロック** し、リトライ / スキップ / 中止を提示します。hook はスロットから独立したグローバルなライブラリに置かれます: 一度書けば、どこにでも取り付けられます。

### 6. あなたのマシンと、あなたのスマートフォン

接続先のホストはステータスバーの **スイッチ** で、ターミナルボタンの隣にあります。これを切り替えると、ワークスペース一覧もセッションも稼働中のエージェントも git の変更も内蔵ターミナルも、すべて *そのマシンの* ものになります。

- LAN 越しの **ダイレクト**、あるいは **SSH**、あるいは 2 台が互いに見えないときは **エンドツーエンド暗号化されたリレー** 経由。リレーが運ぶのは暗号文だけで — セッションを読むことはできず、ルームは daemon の公開鍵から導出されます。
- ヘッドレスな Linux マシンでは **daemon** を動かします: `myflowforge-daemon pair` がターミナルにそのまま QR コードを表示します。読み取ればペアリング完了です。
- **スマートフォンクライアント** (iOS & Android) はビューアーではなく本物のクライアントです: ストリーミングされる会話を読み、権限ゲートとプランゲートに答え、変更されたファイルを閲覧し、ワークスペースを作成し、ワークフローを編集し、ホストを切り替えられます。

> **DeepSeek** は DeepSeek Harness です — `npm install -g @deepseek-ai/dsh`。ヘッドレス用のフラグではなくプロファイルで実行形態を選ぶ方式で、myFlowForge は `headless` を使います。3 段階の権限は DeepSeek 自身の `read-only` / `workspace-write` / `danger-full-access` に対応づけられます。キーは `dsh web` (Models ページ) または `DEEPSEEK_API_KEY` で渡してください。

> **Trae** (ByteDance の TraeCode CLI) は npm では配布されていません — 公式の `install.sh` は `traecli` を `~/.local/bin` に置くので、そこが PATH に入っていることを確認してください。ワークフロー内で無人のまま編集させるには、`traecli config edit` を実行して `permission_mode: bypass_permissions` を設定します。

myFlowForge は **API キーを保存せず、リクエストを中継もしません** — あなたのマシンに既にインストールされ認証済みの CLI を動かすだけです。足りないものは設定画面でインストール方法とともに示され、CLI がインストール済みでも未ログインの場合も設定画面が教えてくれます。

## 🔧 実行はどう組み立てられるか

```
   あなたがゴールを説明する
            │
            ▼
  ┌─ hook ─┐        ┌─ hook ─┐                    ┌─ hook ─┐
  │  実行  │        │  設計  │                    │  実行  │
  │   前   │        │   後   │                    │   後   │
  └───┬────┘        └───┬────┘                    └───┬────┘
      ▼                 ▼                             ▼
 📋 要件定義 → 🎨 設計 → ✋ GATE → 💻 開発 → 🧪 テスト → 🔍 レビュー
   (明確化)    (design.md) あなたが判断 (ファンアウト) (検証)  (多視点)
                      │                       │
                      │                       └─ プロジェクトごとに 1 エージェント、
                      │                          並列レーン、専用の worktree
                      └─ 本物のドキュメント。下流のエージェントが全文を読む

 どの矢印も、あなたが「次へ」を押すまで待ちます。ステージは追加・削除・
 並べ替え・スキップが可能 — 要件定義 → 開発 だけを走らせるのも立派に有効です。
```

開始する方法は 3 つあり、どれも同じゲートにたどり着きます:

1. ワークフローパネルの **開始** を押す。
2. 入力欄で `/` と打って選ぶ。
3. 開発タスク全体をふつうの言葉で説明する — メインのエージェントがそれを認識し、MCP 経由でプランゲートを上げます。質問や議論、1 行の修正では発動しません。

## 📱 リモートホストとスマートフォンクライアント

ひとつのアプリ、複数のマシン。ステータスバーからホストを選べば、すべてがそれに追従します。

| | |
|---|---|
| **ダイレクト** | 同じ LAN で daemon のポートへ直接。トークン認証。 |
| **SSH** | 既にあなたが持っている SSH ログインを再利用 — 新しく開けるものはありません。 |
| **リレー** | 互いに見えないマシン向け。**エンドツーエンド暗号化**: セッションごとに新しい鍵、リレーは暗号文を転送するだけ、読めないフレームは信用せず破棄します。自前で運用も可能 (`relay/`、Node または Cloudflare Worker) — 手順は `relay/README.md` にあります。 |

**Linux daemon** はウィンドウのない同じコードベースです — tarball をインストールして systemd で動かし、ターミナルに表示される QR コードを読み取ってペアリングします (`docs/linux-deploy.md`)。

**スマートフォンクライアント** はデスクを離れているときに実際に必要な部分をカバーします: ストリーミングされる思考、ツールカード、サブエージェントカードつきのライブ会話、答えられる権限ゲートとプランゲート、変更ファイルと差分、ワークスペースの作成、ワークフローのテンプレートライブラリ、ホストの切り替えと QR ペアリング。markdown、表、ローカル画像はネイティブに描画されます — リモート画像のアドレスは意図的にリンクのままにしてあるので、エージェントの出力があなたのスマートフォンを追跡ビーコンに変えることはありません。

## 🧩 同梱されているもの

- **ネイティブセッションのインポート** — ローカルの Claude / Codex / Cursor / qoder の履歴を読み取り専用でスキャンし、ワークスペースとして取り込んで続きから作業できます。
- **MCP ブリッジ** — 内蔵の Forge MCP サーバーにより、エージェントがアプリ側を呼び戻せます: `forge_ask`, `forge_propose_plan`, `forge_write_artifact`, `forge_handoff`, `forge_delegate`, `forge_read_context`, `forge_heartbeat`。MCP に対応するエージェントには注入され、それ以外はテキストの指示にフォールバックします。
- **MCP サーバーとアドオン** — 各 CLI がどの MCP サーバーを設定しているかを確認し、アプリから認可や取り消しを行い、スキルマーケットを見て、それを読む CLI へスキルをインストールできます。
- **メモリー** — ワークスペースごとのメモをエージェントが読み返せるので、長く続く作業が自分の文脈を保ちます。
- **リアルタイムな可観測性** — ストリーミングされる思考 / ツール呼び出し / ファイル変更 / 生の出力、フィルタ可能なログコンソール、実行履歴、そしてプロジェクトを横断した変更の証跡。
- **トークン使用量とクォータ** — プロバイダーごとの残クォータとリセット時刻、さらにワークスペース × エージェント × 日ごとの消費。
- **ボットブリッジ** — **DingTalk**、**Telegram**、**Feishu** から、スマートフォン上でゲートに答え、結果を確認し、会話を始め、ワークフローを動かせます。
- **権限モード** — 読み取り専用 · ワークスペース自動 (既定) · フルアクセスを、セッション単位またはステージ単位で。各 CLI の実際のサンドボックス範囲に対応づけられ、どのエージェントが実際にそれを尊重するかを UI がはっきり示します。
- **スラッシュコマンド、スキル、プラグイン** — `/` を押すとディスク上の実際のコマンドとインストール済みスキルが、エージェントごとに絞り込まれて出てきます。
- **カスタムワークフロー** — プロセスはあなたが組み立てるものです: 名前付きのワークフローを好きなだけ保存でき、それぞれが独自のステージ構成を持ちます。各ステージはエージェント、モデル、権限モード、ファンアウトの形、ゲートするかどうか、ドキュメントを必ず生成するかどうかを選べます。
- **カスタムステージ** — 自分だけのステージのグローバルライブラリ。どのワークフローからも参照できます。
- **ファイルブラウザーと差分** — 変更マーカー付きの全画面ツリー、シンタックスハイライト付きプレビュー、差分と全文の切り替え。
- **内蔵ターミナル** — ワークスペースを起点とする本物の pty。プロバイダーごとのプロキシとタイムゾーン設定つき。リモートホストに接続していれば、**そのマシン上の** シェルが開きます。
- **デスクトップペット** — フォーカスしている画面を追いかけ、エージェントの動きをプレビューし、確認カードを出します。ペットマーケットを見るのも、自分の画像を持ち込むのも自由です。
- **育成ペット** — 作業を進めるとデスクトップペットが段階的に成長するので、長いセッションが目に見える何かを残します。
- **透過とすりガラス** — ぼかしのスライダー 1 本で、ウィンドウ全体を完全な不透明から macOS ネイティブの 3 種類の vibrancy マテリアルまで動かし、デスクトップを透かして見せます。
- **パーソナライズ** — オリジナルスキン 6 種、アクセントカラー 12 色、300 枚以上の壁紙ギャラリーまたは自分の写真、アプリとチャットで独立したピクセル単位のフォントサイズ、ライトとダークで別々にコントラストを調整。
- **壁紙駆動のテーマ** — 有効にすると、選んだ壁紙からパレット全体が導かれ、ライトかダークかは画像自身が決めます。壁紙が提供するのは 2 つの色相だけで、明度と彩度の刻みはすべて手で調整済みのスキンから写されるので、にぎやかな写真でも読めない画面にはなりません。自分のアクセントカラーがいい? 選べば、アクセントだけが追従をやめます。
- **チャット内の画像とインラインビジュアル** — エージェントがディスク上に生成した画像は返信の中に描画され、クリックすると原寸で見られます。回答の途中で書かれた HTML 断片は、本物のカードや表や図として描画できます (既定はオフ)。`innerHTML` は決して使わず、断片は構成的な許可リストからパースして組み直され、色はテーマトークン由来のものしか使えません。だから描画された内容はスキンと喧嘩せず、それに従います。

| Android | `myFlowForge-<version>.apk` |
| Linux · ヘッドレス daemon | `myFlowForge-daemon-<version>-linux.tar.gz` |

> **アプリはコード署名されていません。** macOS では初回起動時に *「開けません」* や *「壊れています」* と言われることがあります — それが未署名アプリの見え方であって、ファイル自体は問題ありません。**右クリック** → **開く** → **開く** とするか、一度だけ次を実行してください:
> `xattr -dr com.apple.quarantine /Applications/myFlowForge.app`
> Windows の SmartScreen では **詳細情報 → 実行** が必要です。
>
> myFlowForge はこの同じ Releases フィードを確認し、新しいバージョンをアプリ内で提示します。

**iOS** はダウンロード配布していません — `mobile/` から自分の Apple ID でビルドし、ケーブル経由で自分の端末にインストールしてください。

## 🚀 はじめかた

**前提条件:** macOS 11+ / Windows 10+ / 新しめの Linux、Node.js ≥ 20、git、そして対応コーディング CLI が少なくとも 1 つインストール・認証済みであること。

```bash
git clone https://github.com/flowForges/myFlowForge.git
cd myFlowForge
npm install
npm run dev          # レンダラーのホットリロード付き開発モード
```

| コマンド | 内容 |
|---------|--------------|
| `npm run dev` | ホットリロード付きで起動 |
| `npm test` | テストスイート全体を実行 (Vitest) |
| `npm run typecheck` | main と renderer 両方の tsconfig を型チェック |
| `npm run build` | 本番バンドルをビルド |
| `npm run dist:mac-all` | Intel と Apple Silicon 両方の `.dmg` をビルド |
| `npm run dist:win` | Windows x64 インストーラーをビルド |
| `npm run check:daemon` | ヘッドレス daemon をエンドツーエンドで動作確認 |

スマートフォンクライアントは `mobile/` (Expo / React Native)、リレーは `relay/` にあります。どちらも独自の `package.json` を持っています。

成果物は `release/` に出力されます。`src/main/**` 配下の変更には **Electron の完全な再起動** が必要です — ホットリロードはレンダラーしか更新しません。

```
src/
├── main/              # Electron メインプロセス

│   ├── remote/        # リモートホスト: direct / SSH / relay、ルーティング、E2E チャネル
│   ├── daemon/        # ヘッドレス daemon + ターミナル QR ペアリング
│   ├── bot/           # ボットブリッジ (DingTalk / Telegram / Feishu トランスポート)
│   ├── plugins/       # プラグインホスト、カタログ、スケジューラー、拡張ポイント
│   ├── sessionImport/ # ネイティブセッションのスキャンとインポート
│   ├── usage/         # プロバイダーのクォータアダプター
│   ├── pet/           # デスクトップペットのウィンドウ
│   └── ...            # git、fs、ターミナル、更新、ウォッチャー、ウィンドウ、外観
├── renderer/          # React の UI (ビュー、コンポーネント、設定、テーマ、ペット)
├── preload/           # コンテキスト分離された IPC ブリッジ
└── shared/            # プロセス間で共有する型と純粋ロジック
mobile/                # iOS & Android クライアント (Expo / React Native)
relay/                 # エンドツーエンド暗号化リレー (Node または Cloudflare Worker)
```
